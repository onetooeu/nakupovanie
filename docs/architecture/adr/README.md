## ADR Rules

- Do not edit an accepted ADR to pretend the historical decision was different.
- Material changes should create a new ADR that supersedes or amends the earlier decision.
- Keep context, decision, consequences, and alternatives explicit.
- Link implementation work to the relevant ADR when the relationship is material.
